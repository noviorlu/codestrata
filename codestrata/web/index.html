怎么读这张图

怎么操作

  • 点节点在下面的抽屉里看模块：依赖谁、文件树、类 / 函数、解读；再点一次、点空白处或按 Esc 取消选中。
  • 点箭头看这条依赖具体用了对方哪些函数 / 类、在哪一行。
  • 节点左上角的 ＋ 就地展开成子模块（框在一个框里），框头的 − 收起；展开 / 收起不会取消选中。
  • 缩放：图左上角的 ＋ / －，或按住 Ctrl 滚滚轮；✥ 打开后按住任意位置拖动图。现在图比图框宽：按住空白处也能拖，或 Shift + 滚轮横着滚。
  • 全文窗口和源码片段里，按住 Ctrl（Mac 上 ⌘）点名字跳到定义，旁边一栏列出定义和所有引用。
  • 右上角的搜索：/ 或 Ctrl+K；按名字找模块、文件、类 / 函数，词里带 . 或 / 才按路径找。拖左边 / 下边改大小。
  • 下面的详情栏浮在图上：点标题栏展开 / 收起，拖上沿 / 左右边框改大小。
