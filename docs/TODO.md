## P0：先还债（在加任何功能之前）

1. **前端测试进仓库**
   - 为什么：浏览器测试在开发机临时目录里，依赖本机录制，别人跑不了，回归迟早出。
   - 做到：`tests/web/` 下的 headless Chrome 测试，用仓库里假服务录的 run 当固定数据，随机端口、自己清理进程。
     覆盖：图、叠加、时间轴、时间顺序、对比、代码窗口、查找。一条命令跑完，没有 Chrome 就跳过。
2. **拆 `trace.py`**
   - 为什么：它混了三件运行环境不同的事——被测进程里的 hook、外面的 driver、加载时的分析。
   - 做到：拆成三个模块：hook（只在被测进程里跑）、driver（进程组、信号升级、扫残留）、
     加载时的分析（`merge`、`to_package_graph`、`sym_locs`、`defining`、`resolve_phase_at`、`case_script`，
     runs / seq / jobs / `__main__` 改成依赖它）。测试全绿；注入到被测进程的代码不 import driver。
3. **私有名字公开**
   - 为什么：别的模块在用，说明它是接口。
   - 做到：`codestrata/` 里既没有 `_模块._名字` 的用法，也没有 `from .模块 import _名字`（函数里的也算），
     `runs.py` 里 `_proc_start = _trace._proc_start` 这种别名也去掉。
