## 2026-09-29（开发者自评 + 外部评价）

- **严重** 读 hot 图时我自己都要回想「调用方是最近的仓库内帧」：从框架事件循环回调进来的调用，看起来像是直接调用。界面上没有任何提示。
- **严重** 对比两个 run 只有三种颜色，要回答「两次差在哪」还得一条条点边看，没有清单。
- **中** 时间轴上 serving 只占整条的 4%（启动约 100 s），不点阶段按钮放大，几乎拖不动。
- **中** 读代码类功能越做越多（跳转定义、查找栏、搜索、JS 高亮器），但用户手边本来就有编辑器，这部分是在做一个更差的 VS Code。
- **中** 本仓库的解读每改一次代码就要花大量 token 刷新行号和哈希，写出来的东西人读不下去。
- **低** 开发过程中起了十几个 serve 进程从不清理；临时目录堆了几百个文件。
- **低** run 里有几个字段写了但没有任何代码读：`schema`、`sizes`（而且 `run.json` 那一项取在最后一次写入之前，值是错的）、
  `sha_of`、`sha_late`、`captured`、`git.dirty`、spans 索引里的 `pairing`。要么用起来，要么别写（见 `docs/design/run-format.md`）。
